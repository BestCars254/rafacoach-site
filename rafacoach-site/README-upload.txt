RafaCoach サイト更新用ファイル
=====================================

【中身】
  index.html   … 新デザインのトップページ（特商法・プライバシーのページも中に入っています）
  img/         … 写真26枚（i0〜i24 と OGP用の og.jpg）※GitHubにある物と同じファイルです
  CNAME        … rafacoach.jp（現在の設定と同じ内容。念のため同梱）

【GitHubでの更新手順】
  1. https://github.com/BestCars254/rafacoach-site を開く
  2. 「Add file」→「Upload files」をクリック
  3. このフォルダの index.html をドラッグ＆ドロップ
     （img と CNAME は既にGitHub上にある物と同じなので、アップロード不要です）
  4. 下の「Commit changes」を押す
  5. 1〜2分待ってから https://rafacoach.jp/ を再読み込み
     （表示が変わらない場合は、スーパーリロード：Windows は Ctrl+F5、Mac は Shift+⌘+R）

【注意】
  ・CNAME は絶対に削除しないでください。削除すると rafacoach.jp が使えなくなります。
  ・img フォルダも削除しないでください。写真が表示されなくなります。
  ・index.html だけを差し替えれば更新は完了します。
